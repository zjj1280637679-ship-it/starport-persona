# 明清人物镜 · 独立 GitHub Pages 子站

访问地址：https://zjj1280637679-ship-it.github.io/starport-persona/mingqing-mirror/

本目录独立于原项目“暮灯星栈”，不引用、不修改原酒馆的题库或代码。
网页是无需构建的 ESM 原生 HTML/CSS/JavaScript 站点，GitHub Pages 可直接使用。

## 现阶段功能
- 首页 → 速鉴12问/史鉴28问 → 单题开放回答/有唯一标准答案的智谋题 → 四维报告 → 本机卷宗。
- 四维严格分离：人格4轴、政治6轴、血汉/血满/血回/血蒙历史阵营共鸣4项、智谋成绩。
- 历史人物准入：智谋成绩达到人物档位门槛（0/30/55/75），然后在**准入池内**以四组向量距离做最近邻拟合；永远找最近的实际历史人物，低相似会提示差异而非拒绝匹配。虚构兜底档案不参与排名。
- 28题（4类各7题），其中21道开放文本题、7道有标准答案智谋题；12题速鉴各选3道。
- 当前是**离线词库+可选倾向标记**评分演示，不是假装 AI，也不把族群身份视作智力/政治/人格本质。
- 回答和报告默认仅保留本地 localStorage；没有账户、数据库或远端上传。
- 用户的原文句柄只用于同一份测试中**安全同义槽位**的措辞替换；不能保证任意回答都触发，没把握就保持原题；无隐藏追问。

## 美术升级路线（严格遵循）
**graphic 图形 → image 静态图片（WebP/PNG） → gif 动态 GIF**。

槽位在 `media.js` 中集中维护，不在题库内散落图片 URL。
资源文件放 `assets/` 目录。原始图形 SVG 形状由 `media.js` 内置生成，缺图会退回默认形状。

主要槽位：
| ID | 放置区域 | 优先比例 |
|---|---|---|
| `home.background` | 固定全局底图 | 16:9 / 超宽 |
| `home.hero` | 首页主场景 | 7:6 / 16:10 |
| `question.default` | 题目无专属图时兜底 | 16:9 |
| `question.p1`、`question.g1` 等 | 各题历史场景 | 16:9 |
| `character.default` | 无专属肖像的兜底 | 4:5 |
| `character.chongzhen` 等 | 具体历史人物肖像 | 4:5 |
| `result.banner` | 结果的背景插画预留 | 16:9 |
| `card.frame` | 人物/结果卡纹章边框 | 3:4 / 透明图 |
| `icon.brand`、`icon.scroll` 等 | 符号图标 | 1:1，透明图 |

示例：把首页主图从图形切换为静态图片：

```js
// media.js 的 MEDIA 对象内
"home.hero": {
  mode: "image",
  src: "./assets/home-hero.webp",
  alt: "晚明宫城远景"
}
```

改成 GIF 时仅需 `mode: "gif",src:"./assets/home-hero.gif"`。尽量让 GIF 短、可循环、体积轻；长动画未来可支持 WebM/MP4（本版未实现）。必须提供静态图或原生图形作为加载错误回退，尊重减少动画的无障碍偏好。

## 模块
- `index.html`：HTML 入口/全局导航
- `styles.css`：页面样式、美术占位容器、响应式
- `data.js`：题库、测量轴、人物游戏推定、测试模式
- `app.js`：答题状态、评分、等级过滤、最近邻、报告、卷宗
- `media.js`：素材 manifest 与图形占位渲染器
- `assets/`：未来 WebP / PNG / GIF

## AI 升级边界
GitHub Pages 是静态托管，不能把 AI API 密钥放进 `app.js`。如接入真实 AI 语义分析/句柄同义改写，必须使用后端代理和严格 JSON 契约；失败立即回落原题及离线解析。不让 AI 改题目测量目标、智谋正确答案和评分权重。不能把没有真实用户原文句柄的改写包装为 AI 互动。
