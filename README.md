# 暮灯星栈 · 文明倾向酒馆（GitHub Pages）

## 网站

公开访问：https://zjj1280637679-ship-it.github.io/starport-persona/

本仓库是免费游客版，面向手机与桌面浏览器，只有**一个完整的文明倾向酒馆测试**。由用户提供的「暮灯星栈」原始源码改造成 GitHub Pages 可直接运行的静态站点。

## 体验

- 49 道原创题，每次根据条件分支和随机路径进行 14 道访谈。
- 4 个思潮维度，8 个思潮方向，生成文明档案和国策。
- 趣味题目与开放文字不计分。
- 内置本地酒保评语与文明卡下载。
- 无需注册、无需数据库、没有外部 CDN，题目不上传服务器。

## 部署

已按 GitHub Pages 的项目站点子路径配置了相对资源路径。Settings → Pages → Deploy from a branch → main → /(root)。提交到 main 后 Pages 自动发布。

## 说明

仅为原创娱乐测评，没有经过心理测量学验证，不能当作心理或政治身份诊断。

原始源码同时提供了 DeepSeek 服务端评语代码，但 GitHub Pages 不能运行后端，也不能安全存放 API Key，所以公开免费版暂时不展示 AI 调用入口。以后可以单独部署安全的后端，再接入可选 AI 评语。
